# SABONG24 Football Scores Bot

A Telegram bot focused only on football scores, fixtures, and live match updates.

## Commands

- /start — Start the bot
- /live — Current live football scores
- /today — Today's fixtures and results
- /help — Command list

## Required environment variables

- TELEGRAM_SCOREBOT_TOKEN — Telegram token for this separate score bot
- API_FOOTBALL_KEY — API key for football data

For security, keep both values in your hosting provider's environment/secret settings. Do not commit them to GitHub.

## Data

Football match data is retrieved from API-Football at runtime. The bot is not affiliated with Telegram or API-Football.

## Advertising

The bot is designed around factual football scores and fixtures only. It does not provide betting odds, gambling services, or wagering instructions.
